앱 사용 방법
1. 항목 설정하기
'항목관리' 탭에서 관리하고 싶은 검사 항목을 추가하세요. 추천 항목을 터치하거나 직접 추가할 수 있습니다.
2. 새로운 수치 기록하기
'기록' 탭에서 검사받은 날짜를 선택하고, 빈칸에 수치를 입력한 뒤 '저장' 버튼을 누르세요. / 단위의 경우 병원마다 상이할 수 있습니다.
3. 기존 기록 수정하기
날짜 선택 ➜ '불러오기' 클릭 ➜ 수치 수정 ➜ '저장'를 누르면 정상적으로 덮어쓰기 수정이 완료됩니다.
4. 기존 기록 삭제하기
날짜 선택 ➜ '삭제' 클릭 ➜ 확인을 누르면 그 날짜의 기록이 바로 삭제됩니다.
5. 그래프로 추이 보기
'그래프' 탭에서 원하는 항목과 기간을 선택해 추이를 한눈에 확인하세요.
6. 주기적으로 백업하기
이 앱은 서버 기반 앱이 아니므로 기록을 주기적으로 백업해두는 것이 꼭 필요합니다. 설정 탭의 '데이터 백업' 버튼을 눌러 백업 파일을 안전한 곳에 보관해주세요.
1. Set up your items
In the Items tab, add the tests you want to track. Tap a suggested item or add your own.
2. Record new values
In the Record tab, pick the test date, type in your values and tap Save. Units can differ between labs.
3. Edit a past record
Pick the date ➜ tap Load ➜ change the values ➜ tap Save to overwrite it.
4. Delete a past record
Pick the date ➜ tap Delete and confirm. The record is removed right away.
5. See the trend
In the Chart tab, choose an item and a period to see how it has changed.
6. Back up regularly
This app has no server, so regular backups matter. Tap Back up in Settings and keep the file somewhere safe.
